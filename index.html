내가 맡은 부분 — 안드로이드 클라이언트의 오디오 수집 구조 설계와 PyTorch 기반 감정 인식 모델 구현. MediaRecorder로 녹음과 파일 저장 흐름을 구성했고, librosa로 16kHz 리샘플링 · Z-score 정규화 · 가우시안 노이즈와 랜덤 SNR 증강 · log-Mel 스펙트로그램 추출까지 전처리를 맡았습니다. 기능 명세서도 작성했습니다.

어려웠던 점과 해결 — 정확도가 잘 오르지 않아 한동안 모델 구조만 바꿔가며 실험했는데 효과가 없었습니다. 문제가 모델이 아니라 입력에 있다고 보고 전처리를 다시 손봤습니다. 샘플링 레이트를 맞추고 Z-score로 정규화한 뒤 log-Mel 스펙트로그램으로 입력 형태를 바꾸고, 가우시안 노이즈와 랜덤 SNR 증강을 더하고 나서야 검증 정확도가 80% 수준까지 올라갔습니다. 음성에서는 모델 구조보다 전처리와 입력 표현이 성능을 더 크게 좌우했습니다.

내가 한 것 — 데이터 수집과 결측치·이상치 확인, 변수 선택과 전처리, 히트맵으로 9개 속성과 우울증의 상관관계 분석, 여러 모델을 만들어 정확도와 안정성 비교, 설문 설계와 배포, 결과 해석, 논문 작성

모델을 만들고 끝내지 않았습니다 — 인도네시아 거주 한인과 학교 학생 45명 설문에 적용해 29명이 우울증 의심으로 나왔습니다. 히트맵에서는 집중력 저하, 가족 문제, 자살 시도 순으로 연관이 높았습니다. 두 집단의 차이를 국가 차이로만 보지 않고 생활 환경의 변화, 문화적 적응, 가족과의 거리, 익숙한 사회적 관계로부터의 단절과 연결해 해석했습니다. 이후 학생들의 인지도가 낮은 것을 확인하고 웹사이트와 포스터를 만들어 교내 캠페인까지 진행했습니다.

복지찾기 — 맞춤 복지 추천 서비스

어려웠던 점과 해결 — 맞춤 추천을 하려면 나이·소득·거주지 같은 민감한 정보를 받아야 하는데, 이걸 서버에 쌓아 두는 게 계속 마음에 걸렸습니다. 기존 서비스를 조사하다가, 개인정보를 보관하기 때문에 유출 위험이 생긴다는 걸 보고 아예 저장하지 않는 쪽으로 방향을 잡았습니다. 입력값은 그 자리에서 프롬프트를 만드는 데만 쓰고 버립니다. 보관하는 게 없으니 유출될 것도 없습니다. 대신 로그인도 기록 조회도 포기해야 해서, 무엇을 잃고 무엇을 지킬지 고르는 문제라는 걸 여기서 처음 체감했습니다.

또 하나는 LLM 응답이 매번 다른 모양으로 와서 화면이 깨지는 문제였습니다. 받을 JSON 형태를 먼저 정해 두고 그 틀에 맞춰 응답을 받게 바꾸고 나서야 화면 쪽 코드를 건드릴 일이 없어졌습니다.

어린이보호구역의 CCTV가 대부분 사고 이후 확인 중심이라 위험구간을 미리 피하도록 안내하기 어렵다는 문제에서 출발했습니다. 시간대·구간별 이동체 공공데이터로 위험구간을 먼저 찾고, 위험 노출을 줄인 안전경로를 추천하며, SOS와 드론 현장 확인까지 연결했습니다. 대구 달서구 4개 초등학교로 프로토타입을 만들었습니다.

지도 학습 대신 비지도 학습(Isolation Forest)을 골랐습니다. 사고 예방이 목적이면 사고가 날 뻔한 상황까지 위험으로 봐야 하는데 그건 라벨링이 불가능합니다. 정답지가 없어 정확도를 낼 수 없는 대신, 모델이 뽑은 위험구간과 TAAS의 실제 사고 발생 좌표의 공간적 일치율을 대리 지표로 써서 교차 검증했습니다. 경로는 OSMnx 도로망에 패널티를 주되 우회가 1.2~1.3배를 넘지 않게 튜닝했습니다.

폐암 예측 모델과 적용

CT·기관지내시경 같은 검사 과정이 복잡해 초기 발견이 늦어진다는 문제에서 시작한 논문입니다. 환자 309명의 15개 속성으로 로지스틱 회귀(92%)와 딥러닝(92.47%, 오차 0.18)을 비교했고, 히트맵에서 상관관계가 낮게 나온 '동조 압력' 특성을 빼자 딥러닝 정확도가 93.55%로 올랐습니다.

특성을 더 넣는 게 항상 좋은 건 아니라는 걸 여기서 처음 확인했습니다. 상관관계가 낮은 변수가 오히려 노이즈로 작용했고, 이후 프로젝트에서 입력 변수를 먼저 살펴보는 습관이 생겼습니다. 대기질이 나쁜 인도네시아 거주자 32명에게 적용해 26명이 위험군으로 나왔습니다.

점자 이미지 인식 · 번역

공공시설물에 잘못 부착되거나 관리되지 않은 점자 때문에 시각장애인이 겪는 정보 접근의 어려움에서 출발했습니다. Kaggle Braille Character Dataset 1,560장으로 점자 이미지를 알파벳으로 분류하는 CNN 모델을 만들어 테스트 정확도 88.14%를 얻었고, CAT 같은 단어도 분류할 수 있었습니다.

점자는 여섯 개 점의 조합이라 이미지 안에서 점의 위치와 형태를 유지한 채 학습하는 게 중요하다고 봤습니다. 그래서 완전연결 구조 대신 공간적 특징을 보존하는 CNN을 썼고, 패딩으로 가장자리 정보 손실을 줄이고 조기 종료로 과적합을 막았습니다. 계층을 깊게 쌓는 것보다 문제의 구조적 특성을 먼저 이해하는 게 중요했습니다.
