남상혁 포트폴리오

해커톤과 아이디어톤, 동아리 프로젝트에서 맡았던 작업 14건을 한곳에 정리했습니다.

바로 보기: https://hyuck121212.github.io/portfolio/

무엇을 만들었는가

인공지능 모델과 데이터 분석을 맡았던 작업들을 수상 프로젝트, 그 밖의 개발과 연구, 수업 과제의 세 단으로 나눠 실었습니다. 팀으로 한 작업은 전체 결과와 제가 맡은 부분을 나눠 적었고, 진행 중에 막혔던 부분과 어떻게 풀었는지도 함께 적었습니다.

서버를 켜야 동작하는 작업은 코드만 봐서는 실제 움직임을 알 수 없어서, 시연 영상 세 개를 저장소에 함께 넣어 페이지에서 바로 재생되게 했습니다. 논문 두 편도 전문을 PDF로 넣어 링크를 눌러 바로 읽을 수 있습니다.

실행 방법

이 저장소를 내려받아 index.html을 더블클릭하면 됩니다. 설치나 빌드, 서버 실행이 필요 없습니다. 자세한 내용은 실행방법.txt에 적어 두었습니다.

어떻게 만들었는가

HTML, CSS, JavaScript만 썼고 프레임워크나 라이브러리는 쓰지 않았습니다. JavaScript는 지금 보고 있는 섹션을 메뉴에 표시하는 동작 하나뿐이라, 그 파일이 없어도 페이지 내용은 그대로 보입니다.

화면은 수업에서 배운 기준을 적용해 만들었습니다. 흰 바탕을 주색으로 두고 섹션 배경에만 옅은 색을 번갈아 깔았으며, 진한 색은 링크와 버튼, 수상 배지에만 썼습니다. 글자와 배경의 대비는 모든 조합을 확인해 기준을 넘겼고, 링크는 색만으로 구분하지 않고 밑줄과 화살표를 함께 넣었습니다. 여백은 네 배수로 아홉 단계만 정해 두고 그 안에서만 쓰면서, 카드 안과 카드 사이, 섹션 사이에 서로 다른 간격을 줘 선 없이도 묶음이 보이게 했습니다. 모든 버튼과 링크는 작은 화면에서도 누르기 쉽도록 높이를 확보했습니다.

어떤 코드에 어떤 개념을 적용했는지는 css/style.css 주석에 적어 두었습니다. 설계 과정에서 무엇을 왜 그렇게 정했고 무엇을 고쳤는지는 설계및수정기록.pdf에 정리했습니다.

폴더 구성

index.html이 메인 페이지이고 css에 스타일, js에 스크립트가 있습니다. images에는 작품 구조 도식과 상장, 사진이, video에는 시연 영상이, docs에는 논문 전문 두 편이 들어 있습니다.
