컴퓨터그래픽스 Project 1 — 개인 포트폴리오 웹페이지 실행 방법

학번 P2024013735 / 남상혁 / 정보컴퓨터학부 3학년 / 제출일 2026년 10월 1일


1. 배포 주소

   https://hyuck121212.github.io/portfolio/

   GitHub Pages로 배포했습니다. 위 주소를 브라우저에 붙여넣으면 바로 보실 수 있고,
   로그인이나 설치가 필요하지 않습니다. 아래 2번 방법으로 압축 파일에서 직접
   실행하셔도 결과는 같습니다.


2. 압축 파일에서 실행하기

   압축을 풀면 index.html 이 가장 바깥에 보입니다. 이 파일을 더블클릭하면 기본
   브라우저가 열리면서 포트폴리오 첫 화면이 나타납니다. 더블클릭으로 열리지 않으면,
   브라우저 창을 띄워 놓고 index.html 파일을 그 위로 끌어다 놓아도 됩니다.
   Windows와 macOS 모두 같은 방법으로 열립니다.

   설치, 빌드, 서버 실행, 패키지 설치가 모두 필요 없습니다. index.html 하나만
   열면 전체 페이지가 동작합니다.

   다만 폴더 구조는 그대로 두어야 합니다. index.html 은 같은 폴더의 css, js,
   images, video, docs 를 상대 경로로 불러오기 때문에, index.html 파일만 다른
   곳으로 옮기면 글만 보이고 그림과 영상이 나오지 않습니다.


3. 인터넷 연결과 글꼴

   인터넷이 없어도 내용, 배치, 색, 이미지, 영상이 모두 그대로 동작합니다.
   Pretendard 글꼴만 인터넷에서 불러오는데, 연결이 없거나 차단된 환경에서는
   시스템 기본 글꼴로 바뀌어 표시됩니다. 글자 모양만 달라질 뿐 내용과 배치는
   유지됩니다. 강의자료 W03L1의 '점진적 향상'을 따라, HTML 위에 CSS를, 그 위에
   JavaScript를 쌓아서 바깥에서 불러오는 것이 실패해도 내용은 남도록 만들었습니다.


4. 시연 영상 보는 방법

   시연 영상 3개가 압축 파일 안에 들어 있어 인터넷 연결 없이도 재생됩니다.
   Interview Helper 카드에 앱 시연 영상 2분 16초, Daegu EATMAP 카드에
   아이디어톤 발표 영상 1분, 디저트픽 카드에 웹 시연 영상 1분 26초이 있습니다.

   페이지를 열 때 영상을 미리 내려받지 않도록 설정해 두어서, 재생 버튼을 누르기
   전에는 표지 이미지만 보입니다. 첫 화면이 빨리 뜨도록 한 것이며 고장이 아닙니다.

   브라우저마다 재생할 수 있는 형식이 달라 MP4와 WebM 두 가지를 함께 넣었습니다.
   둘 다 재생되지 않는 환경에서는 영상 자리에 안내 문장이 대신 보이며, 그런 경우
   video 폴더의 파일을 직접 열어 보실 수 있습니다.


5. 작은 화면에서 확인하기

   브라우저 창의 가로 폭을 좁혀도 글과 이미지가 잘리지 않습니다. 폭 320px부터
   1440px까지 확인했습니다.

   개발자 도구로 확인하시려면 index.html 을 브라우저로 연 뒤 F12 를, macOS에서는 Option + Command + I 를 눌러 개발자 도구를 열고, 왼쪽 위 기기 모양 아이콘을
   눌러 기기 목록에서 iPhone 등을 선택하시면 됩니다.

   Chrome, Edge, Safari 최신 버전에서 확인했습니다.


6. 파일 구성

   index.html 은 메인 페이지로, 전체 내용이 이 파일 하나에 들어 있습니다.

   css/style.css 는 전체 스타일입니다. 수업 개념을 적용한 부분마다 피츠의 법칙,
   게슈탈트 근접처럼 어떤 개념을 썼는지 주석으로 적어 두어, 어느 코드가 어느
   수업 내용인지 바로 찾을 수 있게 했습니다.

   js/main.js 는 지금 보고 있는 섹션을 위쪽 메뉴에 표시하는 동작 하나뿐입니다.
   이 파일이 없어도 페이지 내용은 그대로 보입니다.

   images 폴더에는 작품 구조 도식 5개와 그래프 1개를 SVG로, 상장과 수료증,
   활동 사진, 아이프티 로고, 프로필 사진, Daegu EATMAP 발표 자료에서 가져온
   그림 4장, 시연 영상 표지 3장을 JPG로 넣었습니다.

   video 폴더에는 시연 영상 3개가 MP4와 WebM 두 형식으로 들어 있습니다.

   docs 폴더에는 논문 전문 2편이 있습니다. paper-depression.pdf 는 우울증 예측
   모델과 적용으로 48쪽, paper-lungcancer.pdf 는 폐암 예측 모델과 적용으로
   40쪽입니다.

   그 밖에 이 파일인 실행방법.txt 와 설계 결정 및 AI 사용 내역을 적은
   설계및수정기록.pdf 가 함께 들어 있습니다.


7. 외부 링크 안내

   페이지 안의 외부 링크는 모두 새 창에서 열립니다. GitHub 코드 저장소 4개와
   GitHub 프로필 1개, Colab 노트북 3개는 우울증, 폐암, 점자, YouTube 영상 3개,
   그리고 압축 파일 안의 논문 PDF 2개로 연결됩니다. 외부 링크는 모두 11개입니다.

   넣기 전에 모두 직접 열어 확인했고, 내용이 비어 있거나 연결되지 않는 주소는
   넣지 않았습니다.


8. 앞으로 작품을 추가하려면

   index.html 안에 "작품 카드 템플릿 시작"과 "작품 카드 템플릿 끝" 주석으로
   표시해 둔 블록이 있습니다. 이 블록을 통째로 복사해 아래에 붙여 넣고 제목과
   설명, 이미지, 링크만 바꾸면 됩니다. CSS는 수정할 필요가 없습니다.
   P2, P3 결과물을 같은 형식으로 이어 붙이기 위해 만들어 둔 구조입니다.
